Fick's Law Algorithm

以物理擴散定律為啟發的找最佳解方法

Hashim, Mostafa, Hussien, Mirjalili & Sallam（2023）
Knowledge-Based Systems 260, 110146 [1]

今天介紹 2023 年提出的 FLA。先解釋名詞，再講這類演算法為什麼出現；接著說明 FLA 其實沒有在模擬擴散，只借用了公式形狀與名稱；最後才是公式、手算例與互動示範。

名詞介紹

最佳化的意思

  • 地圖 ：所有可能的答案
  • 點 ：一個可能的答案
  • 分數 ：這個答案有多好；在 FLA 裡分數 越小越好
  • 目標 ：找到分數最小的那一點

名詞一覽

名詞 意思 在地圖上
最佳化 在很多選擇裡找出最好的一個 找最低點
目標函數 \(f\) 替每個答案打分數的公式；FLA 找最小值 每個位置的高度
候選解 一個可能的答案；FLA 把它叫做「分子」 地圖上的一個點
族群 同時派很多個候選解一起找；FLA 分成兩群（區域 1、2） 一群點
迭代 一輪一輪更新位置；\(t\) 是第幾輪，\(T\) 是總輪數 點每走一步
探索／開發 探索：到處看沒去過的地方；開發：在目前最好的地方附近仔細找 跳遠／小步走
元啟發式演算法 通用的「聰明猜法」：不保證最好，但能很快找到夠好的答案 不必走遍整張地圖

演算法由來

窮舉的困難

77 年

20 個城市的拜訪順序有 20! ≈ 2.4×10¹⁸ 種。電腦每秒檢查 10 億種，也要算大約 77 年（我的計算）

就像要在整片沙灘上找到最漂亮的一顆貝殼，不可能每顆都翻起來看。

所以人們改用「聰明的猜法」：先到處看看，再往看起來不錯的地方仔細找。不保證找到最好的，但能很快找到夠好的答案。這類方法叫做「元啟發式演算法」（metaheuristics）。

例：模擬退火 SA、重力 GSA、 FLA [1][15]

沒有免費午餐定理

  • 「沒有免費午餐定理」：一個演算法在某些題目表現較好，必然在另一些題目表現較差 [14]
  • 所以研究者不斷提出新方法，FLA 就是其中之一 [1]
  • 但也有人批評：許多新演算法只是換了比喻，內容和舊方法差不多 [7] 。例如有研究指出 GSA 其實沒有真的按照重力定律運作 [13]
所以學習 FLA 時，重點是看懂它實際怎麼移動候選解，而不是只記住「擴散」這個比喻。後面的實驗也會看到這一點。

擴散原理

菲克定律

\[ J = -D\,\frac{d\varphi}{dx} \]
  • \(J\)：擴散通量，單位時間通過單位面積的物質量
  • \(D\)：擴散係數（m²/s）
  • \(d\varphi/dx\)：濃度梯度；負號代表流向濃度較低的一側 [6]

白話 　濃淡差越大、距離越短，流得越快；方向永遠是從濃往淡。這是真實的物理現象，氣體、液體、固體中都會發生。

Adolf Fick 在 1855 年提出。第二定律描述濃度隨時間的變化，但 FLA 只用到第一定律的概念：流動方向與濃度差、距離有關。

肺泡氣體交換

  • 氧氣 ：肺泡裡多、血液裡少 → 往血液擴散
  • 二氧化碳 ：血液裡多、肺泡裡少 → 往肺泡擴散
  • 這是 氣體穿過一層膜、溶進液體 的擴散，不需要任何「推力」，只靠兩邊的濃度差 [16]

影響擴散速率的因素

\[ \text{擴散速率} \;\propto\; \frac{\Delta P \times A \times S}{\sqrt{MW} \times d} \]

越大，擴散越快

  • \(\Delta P\)：兩邊的濃度（分壓）差
  • \(A\)：膜的面積；像濾網越大，過得越多
  • \(S\)：溶解度；CO₂ 在液體中的溶解度約為 O₂ 的 22 倍 [16]

越大，擴散越慢

  • \(MW\)：分子量；分子越重跑得越慢（Graham 定律）
  • \(d\)：膜的厚度；像蕾絲窗簾比絨布窗簾容易透氣 [16]
這是生理學常用的菲克定律寫法，把前一頁的擴散係數 D 拆成溶解度與分子量，距離 dx 對應膜厚度 d。前面的 \(J = -D\,d\varphi/dx\) 是同一件事的一般形式 [6]。

擴散與 FLA 的對照

真正的擴散 FLA 實際在做的事
誰在動 真的分子 候選解（地圖上的點）
往哪裡動 從擠的地方 散開 到空的地方 往分數比較好的點 靠攏
由什麼決定方向 濃度高低 哪個點的分數比較好

FLA 沒有在模擬氣體或液體，只借用了公式的形狀和名稱。 擴散最後是「散開」，最佳化最後卻是「聚集」，兩者方向相反。所以不要用擴散的畫面去想 FLA 的每一步，只把它當成名字和靈感來源。

就我讀到的資料（mealpy 程式碼 [3] 與 [4] 的公式重述），FLA 只用「分子在兩個區域之間移動」這個抽象概念，沒有指定是哪一種物質；原論文全文沒能取得。這也呼應了對隱喻型演算法的批評 [7]。

FLA 借用的因素

菲克定律的因素 FLA 有沒有用 換成了什麼
濃度差 \(\Delta P\) 有 兩群點的平均位置之差 \(\bar x_j - \bar x_i\)
膜厚度（距離）\(d\) 有 一個點到最好的點的距離 \(\lVert X_{best} - x\rVert\)
擴散係數 \(D\) 有 固定常數 0.01 [3]
面積 \(A\)、溶解度 \(S\)、分子量 \(MW\) 沒有 —

另外：「分子」換成候選解，「兩個區域」換成兩群點，「擴散 → 平衡 → 穩態」換成「廣泛找 → 開始集中 → 定下來」 [1][4] 。

對應方式以 mealpy 的實作為準 [3]：距離用歐氏範數；論文重述 [4] 中寫成平方差，實作時要留意兩者不同。

FLA 概要

派兩群點去地圖上找最低點：先讓點大範圍亂跳，再讓各群往自己群裡最好的點靠攏，最後全部往整體最好的點收斂；每個點只有在新位置分數更好時才移過去。

擴散 DO

前約 3/4 輪：廣泛找

平衡 EO

中間一小段：各群集中

穩態 SSO

最後一小段：全部收斂

三個階段的比例由下一頁的 TF 公式決定 [3]。「擴散、平衡、穩態」只是名字，用來描述先廣泛找、再集中找的節奏。

演算法步驟

時間函數 TF

\[ TF = \sinh\!\left(\tfrac{t}{T}\right)^{C_1},\qquad C_1 = 0.5 \]
擴散 DO　TF < 0.9
平衡
穩態
t = 0 0.74T 0.88T T

前約 74% 的迭代在擴散（探索），約 14% 平衡（0.9 ≤ TF ≤ 1），最後約 12% 穩態（TF > 1） [3]

比例是由 TF 的門檻反推：sinh(t/T) < 0.81 → t/T < 0.7405；sinh(t/T) ≤ 1 → t/T ≤ 0.8814。注意 [4] 把公式寫成 sinh(t/T)/c1，與 mealpy 程式碼不同，實作請以作者 MATLAB 程式 [2] 為準。

演算法流程

  1. 隨機初始化 N 個解，平分為區域 1、2，各自找出最佳解
  2. 計算 \(TF = \sinh(t/T)^{C_1}\)
  3. 依 TF 執行 DO EO SSO 其中之一，產生新解
  4. 超出邊界的維度截回 \([L, U]\)
  5. 貪婪選擇：新解比舊解好才取代
  6. 更新兩區最佳解與全域最佳解，回到步驟 2 [3][4]

擴散階段 DO

\[ DOF = e^{-C_2 (TF - r)},\quad TDO = C_5\,TF - r \]
\[ x' = X_{best,j} + DF\cdot DOF\cdot \vec r \odot \left(J\,X_{best,j} - x\right) \] \[ J = -D\,\frac{\bar x_j - \bar x_i}{\lVert X_{best,j} - x\rVert + \varepsilon} \]
  • 方向：\(TDO <\) 隨機數時區域 1 → 2，否則 2 → 1
  • 跨區數量 \(NT_{12} = \mathrm{round}\big(N_1(C_3 + r(C_4 - C_3))\big)\)，約為該區的 10–20%
  • 留在原區的分子逐維度：80% 取本區最佳、10% 在最佳附近隨機跳、10% 保持原值
  • 另一區全部：\(x' = X_{best} + DOF\,(\vec r\,(U-L) + L)\) [3][4]

白話 　前約 3/4 輪：大部分點在自己這群最好的點附近大範圍亂跳；少數點跳到另一群最好的點附近看看。

DF 是 ±1 的隨機方向，\(\vec r\) 是每個維度各自的 [0,1] 隨機數，⊙ 表示逐元素相乘。DOF 在 TF 小時較大，所以早期步伐大、偏探索。

平衡階段 EO

\[ x' = X_{best,g} + Q\odot x + Q\odot\left(MS\cdot X_{best,g} - x\right) \] \[ Q = DF\cdot DRF\cdot \vec r,\quad DRF = e^{-J/TF},\quad MS = e^{-f_{best,g}/(f_x+\varepsilon)} \] \[ J = -D\,\frac{X_{best,g} - \bar x_g}{\lVert X_{best,g} - x\rVert} \]
  • \(g\) 是分子所在的區域；兩個區域各自收斂、互不交換 [3][4]
  • \(MS\) 用適應值比例調整步長：自己越差（\(f_x\) 越大），\(MS\) 越接近 1

白話 　中間一小段：每群的點往自己群裡最好的點靠攏，兩群不互相交換。

穩態階段 SSO

\[ x' = X_{ss} + Q\odot x + Q\odot\left(MS\cdot X_{best} - x\right),\quad MS = e^{-f_{ss}/(f_x+\varepsilon)} \] \[ J = -D\,\frac{\bar x - \bar x_g}{\lVert X_{ss} - x\rVert} \]
  • \(X_{ss}\)：全域最佳解；\(\bar x\)：整個族群的平均位置 [3][4]
  • 白話 　最後一小段：所有點都往整體最好的點收斂，在它附近仔細找。

實作觀察（我的推導） 　展開後 \(Q\odot x\) 與 \(-Q\odot x\) 互相抵銷，得到 \(x' = X_{ss} + Q\odot MS\cdot X_{best}\)。目前位置 \(x\) 只透過 \(J\) 與 \(MS\) 間接影響結果，EO 階段也一樣。

mealpy 中區域 1 的 X_best 用區域 1 最佳解、區域 2 用全域最佳解，兩區不完全對稱；是否與原 MATLAB 一致需對照 [2]。

參數預設值

參數 預設 作用
\(C_1\) 0.5 TF 曲線形狀，決定三個階段的長度
\(C_2\) 2 DOF 衰減速度（擴散步長）
\(C_3,\ C_4\) 0.1、0.2 每代跨區分子比例的下限與上限
\(C_5\) 2 TDO：決定擴散方向
\(D\) 0.01 擴散係數，縮放通量 \(J\) [3]

另有 \(\varepsilon\)（極小值）防止除以零。mealpy 的作者認為其中部分參數可能是多餘的 [3] 。

用 4 個點最小化 \(f(x) = x_1^2 + x_2^2\)。\(f\) 是分數：最低點在 (0, 0)，\(f\) 是點到 (0, 0) 距離的平方，越小越好。T = 10、邊界 [−5, 5]、參數用預設值。平均位置：\(\bar x_1 = (0.5, 0.5)\)、\(\bar x_2 = (-1.5, 0.5)\)、\(\bar x = (-0.5, 0.5)\)

這是我設計的示範例子，數字皆以 mealpy 的公式計算；隨機數直接指定，方便手算驗證。

例：\(TF_1 = \sinh(0.1)^{0.5} = 0.1002^{0.5} = 0.3165\)

第 1 代擴散計算

  1. 取 \(r = 0.6\)：\(DOF = e^{-2(0.3165-0.6)} = 1.7630\)
  2. \(TDO = 2(0.3165) - 0.5 = 0.1330 <\) 隨機數 0.4 → 區域 1 → 2，以 \(X_{best,2} = C\) 為目標
  3. \(J = -0.01\cdot\dfrac{(-2,\ 0)}{\lVert C - A\rVert = 5.3852} = (0.003714,\ 0)\)
  4. \(DF = +1,\ \vec r = (0.5, 0.5)\)：\(x' = C + 1.7630\cdot(0.5,0.5)\odot\big((0.0037, 0) - (3,-1)\big) = (-1.6412,\ 4.8815)\)
  5. \(f(x') = 26.52 > 10\) → 淘汰 ，A 維持原位

白話 　A 試著跳到另一群最好的點 C 附近，分數從 10 變成 26.5，變差了，所以留在原地。

N = 4 時 NT12 = round(2 × 0.1~0.2) = 0，實際上不會有分子跨區；這裡假設 A 被選中，只為示範公式。N = 20 時每代約 1–2 個分子跨區。擴散階段步伐大，被淘汰很常見，這正是探索的代價。

第 10 代穩態計算

  1. \(TF = 1.0841\)；全域最佳 \(X_{ss} = B = (-2, 2)\)，\(f_{ss} = 8\)
  2. \(J = -0.01\cdot\dfrac{\bar x - \bar x_1 = (-1,\ 0)}{\lVert B - A\rVert = 5.8310} = (0.001715,\ 0)\)，\(DRF = e^{-J/TF} = (0.99842,\ 1)\)
  3. \(MS = e^{-8/10} = 0.4493\)；取 \(DF = -1,\ \vec r = (0.3, 0.7)\) → \(Q = (-0.2995,\ -0.7000)\)
  4. \(x' = B + Q\odot A + Q\odot(MS\cdot B - A) = (-2,2) + (-0.8986,\ 0.7) + (1.1677,\ -1.3291)\)
  5. \(x' = (-1.7308,\ 1.3709)\)，\(f(x') = 4.875 < 10\) → 取代 A

白話 　A 往整體最好的點 B 靠近，分數從 10 降到 4.88，變好了，所以移到新位置。

驗算捷徑：x' = B + Q ⊙ MS·B = (−2,2) + (−0.2995, −0.7) ⊙ (−0.8987, 0.8987)，結果相同。

實作注意事項

  • 容易局部收斂 ，高維、高複雜度問題精度下降；FLAS 等改良版加入變異與學習策略來補強 [4][8]
  • MS 會除以適應值 ，f 為 0 或負數時可能溢位或方向反轉 [3] ；我建議先把目標函數平移成正值
  • TF 公式的寫法不一致 ：\(\sinh(t/T)/c_1\) 與 \(\sinh(t/T)^{C_1}\)，請以作者的 MATLAB 程式為準 [2][3][4]
  • 偏好原點（我的實驗） ：區域最佳即全域最佳時，SSO 化簡為 \(x' = X_{ss}\odot(1 + Q\cdot MS)\)，等於把最佳解往原點縮放。同樣 60 代，Sphere 誤差中位數約 \(10^{-22}\)，最佳解移到 (2.5, −1.5) 後只到 \(1.7\times10^{-3}\)。測試時請用位移過的函數
  • 參數多 ，部分可能多餘，先用預設值，再針對問題微調 [3]

重點整理

一句話說 FLA 　兩群點在地圖上找最低點：先廣泛亂跳，再各群集中，最後全部收斂；新位置分數更好才移過去。名字裡的「擴散」只是靈感來源。

  • 屬於物理型元啟發式演算法，這一類方法的源頭可追溯到 1975 年的遺傳演算法 [9]
  • 靈感來自菲克第一定律：物質從濃處流向淡處 [1][6]
  • \(TF = \sinh(t/T)^{0.5}\) 把迭代切成約 74% 擴散、14% 平衡、12% 穩態 [3]
  • 已用於 NMPC 控制器參數調整 [5] 與機械設計 [8]
  • 但要看清物理隱喻底下的實際機制 [7] ：例如穩態更新其實是對最佳解做縮放，對原點有偏好
